# Phone Mouse

Telefonni Bluetooth orqali kompyuter uchun sichqoncha sifatida ishlating. Kompyuteringizda alohida dastur o‘rnatish shart emas.

## APK olish
GitHub Actions buildi tugagach, **Actions → Android APK → Artifacts → PhoneMouse-apk** dan APKni yuklab oling.

## Ishlatish
1. Telefonni kompyuter bilan Bluetooth sozlamalaridan juftlang.
2. Ilovada Bluetooth belgisini bosing va kompyuterni tanlang.
3. Touchpad’da barmoq bilan suring; yuqori qismida chap/o‘ng tugmalar va scroll bor.

Android 9 yoki undan yangi versiya kerak.
